# 曦薇空间 · 图片与版权说明

本项目**不内置任何图片文件**，也不下载、转存或再分发第三方图片。封面有三种来源：管理员上传的自有素材、搜索结果原文公开的图片地址、以及站内 CSS 抽象封面。展示授权始终由站点运营方确认。

## 当前实现

- 种子数据不包含任何图片文件或第三方图片 URL。
- 未设置封面时，前台封面、作品封面、角色卡与首页主视觉使用 CSS 抽象排版（暖色渐层、细线网格、字母组合与站内文字），由 `CoverArt.vue` 等组件生成；图片地址失效时自动回退到该版式。
- RSS 采集默认丢弃来源中的图片字段。即使来源提供 `enclosure` 或 `image`，也只有管理员在来源配置中显式设置 `"use_feed_images": true` 后才会保存图片地址。
- 搜索结果的 Web Metadata Adapter 会解析页面 `og:image` / `twitter:image`，仅在地址为公开 `http(s)`、非内网、非标准端口时写入候选的 `cover_url`。系统只保存 URL，不下载、不镜像图片。图片解析失败或地址不安全时，候选仍会正常入库，只是没有封面。
- 重复搜索结果不会覆盖已有 `cover_url`；管理员手动替换或清空封面后，后续搜索结果也不会改回。
- 管理端可在艺人头像 / 封面、作品封面、角色头像、内容封面、事件封面与编辑精选封面处直接上传图片，或填写已获授权的图片 URL。
- 上传接口仅限管理员 / 编辑，单张不超过 10MB，仅接受 JPEG、PNG、WebP；服务端按文件内容识别类型，使用随机文件名并存入 `MEDIA_DIR` 持久化目录，前端不可指定存储路径。
- 公共内容接口不返回原始采集数据，但会返回 `cover_url`；前台按该地址展示。
- 「基础资料 → 资料完善」会统计各实体缺失的头像 / 海报 / 封面与图片覆盖率。该面板只提示缺口，不会自动下载、生成或填充任何图片。

## 为什么默认关闭第三方图片

艺人写真、剧照、杂志封面、品牌物料等通常受著作权、肖像权与平台条款保护。公开可访问不等于允许转载或热链。站内整理文字资料可以通过来源链接指向原文，但不能把未授权图片当作正式素材。

## 管理员操作要求

1. 上传或填写封面 URL 前，确认素材来源与授权范围（官方发布、明确授权、可商用 / 可展示）。
2. 自动写入的搜索封面只是原文图片地址的引用，不等于已获授权。发布候选前应在「内容管理」核验，必要时替换为自有素材或清空。
3. 不要从搜索引擎、粉丝二创、社交平台直接抓取图片上传为站内素材。
4. 不要开启 `use_feed_images`，除非已逐一确认该来源图片的授权。
5. 收到权利方异议时，立即在「内容管理」中移除封面或下架内容，并保留处理记录。
6. 来源链接与文字引用仍需遵守目标站点的转载规则，尽量使用摘要 + 原文链接。

## 来源与引用

站内内容以标题、简短摘要与来源链接的形式呈现，目的是帮助用户定位公开信息。重要事实在收录前经过人工核验。若权利人认为某条内容或链接不适当，可通过站点管理员联系删除。

## 接入授权素材

获得官方或权利人授权后，可通过后台上传图片。图片写入 `MEDIA_DIR`（Docker Compose 使用命名卷 `xiwei_media`），前台通过 `/api/v1/media/<随机文件名>` 公开访问，无需登录。建议同时记录：

- 授权方与授权范围；
- 授权有效期；
- 素材来源与原链接；
- 下架与替换流程。

在授权信息明确之前，继续使用抽象封面是默认且安全的方案。
