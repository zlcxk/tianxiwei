# 曦薇空间 · 图片与版权说明

本项目对艺人图片采取保守策略：**不内置、不默认抓取、不默认展示任何未经确认授权的第三方图片。**

## 当前实现

- 种子数据不包含任何图片文件或第三方图片 URL。
- 前台封面、作品封面、角色卡与首页主视觉均使用 CSS 抽象排版（暖色渐层、细线网格、字母组合与站内文字），由 `CoverArt.vue` 等组件生成。
- RSS 采集默认丢弃来源中的图片字段。即使来源提供 `enclosure` 或 `image`，也只有管理员在来源配置中显式设置 `"use_feed_images": true` 后才会保存图片地址。
- 管理端手动录入内容时，封面 URL 为可选项；只有确认拥有展示授权的素材才应填写。
- 公共内容接口不返回原始采集数据，但会返回管理员确认的 `cover_url`；前台按该地址展示。

## 为什么默认关闭第三方图片

艺人写真、剧照、杂志封面、品牌物料等通常受著作权、肖像权与平台条款保护。公开可访问不等于允许转载或热链。站内整理文字资料可以通过来源链接指向原文，但不能把未授权图片当作正式素材。

## 管理员操作要求

1. 上传或填写封面 URL 前，确认素材来源与授权范围（官方发布、明确授权、可商用 / 可展示）。
2. 不要从搜索引擎、粉丝二创、社交平台直接抓取图片作为封面。
3. 不要开启 `use_feed_images`，除非已逐一确认该来源图片的授权。
4. 收到权利方异议时，立即在「内容管理」中移除封面或下架内容，并保留处理记录。
5. 来源链接与文字引用仍需遵守目标站点的转载规则，尽量使用摘要 + 原文链接。

## 来源与引用

站内内容以标题、简短摘要与来源链接的形式呈现，目的是帮助用户定位公开信息。重要事实在收录前经过人工核验。若权利人认为某条内容或链接不适当，可通过站点管理员联系删除。

## 未来接入授权素材

如后续获得官方或权利人授权，可将图片存入自有对象存储 / 静态资源目录，并在内容记录中填写站内 URL。建议同时记录：

- 授权方与授权范围；
- 授权有效期；
- 素材来源与原链接；
- 下架与替换流程。

在授权信息明确之前，继续使用抽象封面是默认且安全的方案。
