# 曦薇空间 · 使用说明

本文面向普通访客与登录用户，介绍浏览、筛选、收藏与兴趣偏好的使用方式。管理后台操作见 [管理指南](管理指南.md)。

## 浏览内容（无需登录）

打开站点后可以直接浏览公开内容：

- **首页**：查看艺人简介、场景入口、本周精选、为你挑选、最新动态、历史回顾与作品速览。登录后推荐会根据你的兴趣场景调整；未登录访客不展示「为你挑选」，避免与「最新动态」重复。没有可用数据的模块会自动隐藏，不显示空白占位。
- **发现**：默认按有效时间倒序浏览全部公开动态。顶部可按新闻 / 帖子 / 图片 / 视频 / 作品 / 活动 / 日常 / 商务切换；「筛选」中可组合来源平台、来源类型、时间范围、关联作品、关联活动与饭圈场景。列表不使用热度排序，加载更多使用游标翻页。
- **作品档案**：按年份浏览作品，进入作品详情查看简介、角色与关联内容。
- **角色档案**：从作品详情或内容关联进入，查看角色介绍与相关内容。
- **内容详情**：查看标题、摘要、场景与事件标签、来源名称 / 平台、来源链接、可信等级、发布时间与发现时间。所有公开内容都保留来源信息。
- **事件页**：从内容详情的事件标签进入，查看同一公开活动或作品节点的全部相关内容。

### 按作品、角色或活动筛选

在作品详情点击「筛选全部」、或在角色详情点击「相关内容」，会进入发现页并自动带上作品 / 角色条件；也可以在发现页「筛选」中选择关联作品或关联活动。带有关联条件时，页面顶部会出现「正在查看相关内容」提示条：

- 点击提示条中的名称可返回对应作品、角色或活动页；
- 点击「查看全部」清除全部关联条件，回到完整内容流；
- 作品与活动可以同时筛选；选择新的作品会替换当前角色上下文；
- 其他场景与筛选条件可以与关联条件叠加使用。

### 关于内容时效与来源

- 自动采集内容会标注来源与可信等级；重要信息与全部搜索候选经人工审核后才会公开。
- 发布时间可能标注为「来源明确」「时间待核验」或「时间未知」。来源未给出可信时间时，页面显示「发现于 …」，不会把发现时间伪装成发布时间。
- 搜索引擎摘要中的日期通常只是索引时间，因此会显示为「约 …（待核验）」；需要准确时间请以原文为准。
- 不同来源发布时间可能存在差异，页面展示以采集到并核验的时间为准。
- 没有封面或封面加载失败时使用站内抽象封面，不会出现破图；搜索内容的封面来自原文公开的图片地址，是否保留由管理员核验。
- 若来源链接失效，内容仍会保留在站内，便于追溯；正文请通过「阅读原文 / 前往来源核对」访问。

## 注册与登录

- 站点默认**关闭访客注册**，由管理员在后台创建账号或按部署配置开放注册。
- 登录后可以收藏内容、作品与角色，并保存场景偏好。
- 会话默认保持 7 天。退出登录会清除当前浏览器会话。

注册页仅在部署开启 `ALLOW_REGISTRATION=true` 时显示。若页面没有注册入口，请联系站点管理员。

## 收藏

登录后可收藏三类对象：

1. **内容**：在内容详情或卡片上的收藏按钮操作；
2. **作品**：在作品详情收藏；
3. **角色**：在角色详情收藏。

收藏会保存当时的标题、副标题、封面与来源链接快照。若原内容后来被下架或删除，收藏页会显示「内容暂不可用」，但不会丢失你的收藏记录。

在「收藏」页可按全部 / 内容 / 作品 / 角色切换，并取消收藏。

## 兴趣场景与推荐

进入「我的」→「兴趣偏好」：

- 开启你关注的场景（剧粉、颜值粉、综艺粉、日常粉、时尚商务粉、事业粉、活动粉）；
- 使用 1–5 的权重表达偏好强度；
- 可设置默认场景，首页与发现页会优先展示相关内容。

保存后首页「为你挑选」会立即按新偏好重算。发现页固定按有效时间排序，不受兴趣偏好影响，以免把时间线变成热度或个性推荐流。未登录访客不展示「为你挑选」，只看到「最新动态」等通用模块。

## 常见问题

**为什么内容数量不多？**

站点只展示审核通过或规则允许自动发布的内容，并严格保留来源。宁可少而可信，也不填充未经核验的信息。

**为什么某些内容没有图片？**

项目不内置图片文件。管理员确认授权的素材可上传为站内封面；搜索内容可能引用原文公开的图片地址；没有可用封面时会自动使用站内抽象排版。

**为什么某条内容后来看不到了？**

内容可能被审核驳回、下架，或来源被停用。已收藏的内容会保留快照并提示不可用。

**如何申请账号或反馈来源问题？**

联系站点管理员，并提供内容链接或来源链接，便于核验与修正。
