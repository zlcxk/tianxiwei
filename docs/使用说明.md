# 曦薇空间 · 使用说明

本文面向普通访客与登录用户，介绍浏览、筛选、收藏与兴趣偏好的使用方式。管理后台操作见 [管理指南](管理指南.md)。

## 浏览内容（无需登录）

打开站点后可以直接浏览公开内容：

- **首页**：查看艺人简介、今日精选、场景入口、推荐内容、编辑精选、最新动态与作品速览。登录后推荐会根据你的兴趣场景调整。
- **发现**：搜索关键词，或按「剧粉 / 颜值粉 / 综艺粉 / 日常粉 / 时尚商务粉 / 事业粉 / 活动粉」筛选。可进一步组合内容类型、来源类型、发布时间与排序方式。
- **作品档案**：按年份浏览作品，进入作品详情查看简介、角色与关联内容。
- **角色档案**：从作品详情或内容关联进入，查看角色介绍与相关内容。
- **内容详情**：查看标题、摘要、场景标签、来源名称、来源链接、可信等级与发布时间。所有公开内容都保留来源信息。

### 从作品或角色进入筛选

在作品详情点击「筛选全部」、或在角色详情点击「相关内容」，会进入发现页并自动带上作品 / 角色条件。页面顶部会出现「正在查看相关内容」提示条：

- 点击提示条中的名称可返回对应作品或角色页；
- 点击「查看全部」清除该上下文，回到完整内容流；
- 其他场景与筛选条件可以与作品 / 角色上下文叠加使用。

### 关于内容时效与来源

- 自动采集内容会标注来源与可信等级；重要信息经人工审核后才会公开。
- 不同来源发布时间可能存在差异，页面展示以采集到的发布时间为准。
- 若来源链接失效，内容仍会保留在站内，便于追溯。

## 注册与登录

- 站点默认**关闭访客注册**，由管理员在后台创建账号或按部署配置开放注册。
- 登录后可以收藏内容、作品与角色，并保存场景偏好。
- 会话默认保持 7 天。退出登录会清除当前浏览器会话。

注册页仅在部署开启 `ALLOW_REGISTRATION=true` 时显示。若页面没有注册入口，请联系站点管理员。

## 收藏

登录后可收藏三类对象：

1. **内容**：在内容详情或卡片上的收藏按钮操作；
2. **作品**：在作品详情收藏；
3. **角色**：在角色详情收藏。

收藏会保存当时的标题、副标题、封面与来源链接快照。若原内容后来被下架或删除，收藏页会显示「内容暂不可用」，但不会丢失你的收藏记录。

在「收藏」页可按全部 / 内容 / 作品 / 角色切换，并取消收藏。

## 兴趣场景与推荐

进入「我的」→「兴趣偏好」：

- 开启你关注的场景（剧粉、颜值粉、综艺粉、日常粉、时尚商务粉、事业粉、活动粉）；
- 使用 1–5 的权重表达偏好强度；
- 可设置默认场景，首页与发现页会优先展示相关内容。

保存后推荐会立即按新偏好重算。未登录用户看到的是基于时效与可信度的通用排序。

## 常见问题

**为什么内容数量不多？**

站点只展示审核通过或规则允许自动发布的内容，并严格保留来源。宁可少而可信，也不填充未经核验的信息。

**为什么某些内容没有图片？**

项目默认不使用未经确认授权的艺人图片。封面由站内抽象排版生成；只有管理员明确确认授权的素材才会显示。

**为什么某条内容后来看不到了？**

内容可能被审核驳回、下架，或来源被停用。已收藏的内容会保留快照并提示不可用。

**如何申请账号或反馈来源问题？**

联系站点管理员，并提供内容链接或来源链接，便于核验与修正。
